1Tenant lookup and rate limit

The API key selects the organization and project; per-key rate limits apply.

L0Sanitizer

NFKC; strips invisible, tag, bidi and control characters, ANSI, HTML and entities; flags homoglyphs and scores anomalies.

2Split by source, score each part

user and system messagestool results, documentsMCP tool descriptions + poisoning signals

3Detector, three layers fused into one score

L1
Rules

on a skeleton of the text: Vietnamese diacritics, teencode, leetspeak, homoglyphs

L2
Classifier

our own ONNX model (multilingual-e5-small fine-tune), in process

L3
Similarity

embedding match with built-in and per-organization exemplars

Calibration and fusion → injection score 0 to 1

4Fixed thresholds

Direct injection blocks at 0.85; each tool result, document and tool description at INDIRECT_BLOCK_THRESHOLD.

optSpotlighting

Marks tool results as data (SPOTLIGHT=delimit or datamark) before they reach the model.

5CEL policies

Project rules, then organization rules: allow, block, log, or route to a named upstream. They can only tighten the thresholds.

6Output guard

Strips links and images to unknown hosts, redacts personal data and a leaked canary, checks reasoning and tool-call arguments, also when streaming.

Blocked

HTTP 400 content_filter with a request id. The LLM is never called; an alert goes out.
